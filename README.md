## О проекте

Разработано WPF-приложение (.NET Framework) для автоматизации учёта и управления сетью пиццерий. Приложение работает с базой данных Microsoft SQL Server, реализованной в рамках курсового проекта по дисциплине «Технология разработки и защиты баз данных».

### Реализованный функционал:
*   **База данных:** 18 таблиц (города, пиццерии, сотрудники, меню, ингредиенты, склад, клиенты, заказы, оплаты, доставки). Настроены первичные/внешние ключи и каскадное удаление.
*   **Авторизация и регистрация:** Разграничение ролей (Администратор, Пользователь). Пароли хранятся в хэшированном виде (SHA1).
*   **Защита от подбора:** Блокировка после 3-х неверных попыток входа с выводом капчи.
*   **Роль «Пользователь»:** Просмотр, поиск, фильтрация и сортировка данных (личный кабинет).
*   **Роль «Администратор»:** Полный CRUD (создание, чтение, обновление, удаление) для пользователей, категорий и заказов.
*   **Аналитика:** Построение диаграмм (Chart) на основе данных о заказах.
*   **Экспорт:** Выгрузка отчётов в форматах `.docx`, (через Microsoft Word Interop) и `.xlsx` (через Microsoft Excel Interop).
*   **Интерфейс:** Смена светлой/тёмной темы приложения, единый словарь стилей (Open Sans), плейсхолдеры и всплывающие подсказки.
